Data Sources

Where MSR researchers get their data from.

Source Data Provided Description
GitHub Repositories, commits, pull requests, issues, stars The largest code hosting platform; the main source for studying how open-source software is developed.
Stack Overflow Questions, answers, tags, user reputation A developer Q&A site, useful for studying developer problems, knowledge sharing and API usage.
JIRA Issue tracking, sprint data, bug reports An issue and project tracker used by many organizations and open-source projects such as Apache.
App Stores Google Play and Apple App Store reviews, ratings, downloads Mobile app marketplaces whose user feedback reveals bugs, feature requests and user satisfaction.
Travis CI / Jenkins Build logs, test results, deployment data Continuous integration services whose build history shows how software is built, tested and deployed.
Mailing Lists Developer discussions, archives Email archives of project communication, useful for studying collaboration and decision-making.
npm Registry Package dependencies, downloads, versions The JavaScript package registry, used to study software ecosystems, dependencies and library updates.
